# Grant package

ArcFlow is intended to demonstrate a focused, shippable Arc-native infrastructure product rather than a speculative token or generic crypto dashboard.

Current Circle Developer Grant criteria emphasize strong Arc platform alignment, meaningful Circle product integrations, proven shipping ability, traction/path to success and ecosystem impact. ArcFlow's initial milestone set therefore prioritizes a working Arc settlement flow, reusable developer APIs, measurable usage and a clear path to Circle Wallets/CCTP/Gateway integrations.

Suggested initial request: **do not pre-commit to a dollar amount until the current grant portal and milestone expectations are reviewed.** The repository should first establish a working prototype and actual usage evidence.
