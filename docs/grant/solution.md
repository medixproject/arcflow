# Solution

ArcFlow is an open-source, non-custodial payment infrastructure layer for USDC on Arc.

It provides an API and reference implementation for creating invoices, monitoring Arc USDC transfer events, matching payments to invoices, classifying under/overpayments, recording settlement evidence and notifying applications through signed webhooks.

The MVP is deliberately narrow so the project can demonstrate real Arc usage quickly and produce reusable infrastructure for other builders.
