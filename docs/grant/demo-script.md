# Three-minute demo

1. Open ArcFlow.
2. Show the API documentation.
3. Create a 1 USDC invoice for an Arc merchant address.
4. Open the payment page.
5. Send a small real USDC amount on Arc mainnet.
6. Show the Arc explorer transaction.
7. Run or wait for the monitor.
8. Show ArcFlow detecting the USDC Transfer event and recording the transaction evidence.
9. Show the invoice moving through `confirming` to `paid` according to the configured confirmation policy.
10. Show the signed webhook delivery.
11. Show the API response containing transaction evidence.
12. Show the open-source repository and tests.
